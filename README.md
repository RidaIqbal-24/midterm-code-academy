# midterm-code-academy
Nexus code academy
HTML: I use their semantic html elements such as :
header, navigation, main, footer, section, cards, div, paragraph, heading , span, hero.
CSS: Use margin, padding, flex, text alignment, background color, grid .
I made my website responsive by using a flexible container width, CSS Grid, Flexbox, and CSS media queries. I used a breakpoint at 768px for tablet screens and 480px for mobile screens. These adjustments help the navigation, course cards, About section, students benefits section, and footer adapt to different screen sizes.
